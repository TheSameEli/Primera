BandaStation - Modules - Types — Var Details - Proc Details

transmitter
/obj/structure/transmitter

A wired telephone base; each call owns a reciprocal peer and a cancellable timeout.

Vars

call_soundActive handset or ringer sound, stopped on every state transition.
call_timerStoppable ring timeout, canceled before the next call can start.
callers_listLast five incoming/outgoing calls, storing strings rather than atom references.
current_callReciprocal connection, reserved while ringing as well as while talking.
display_nameLabel displayed in the directory and call history.
