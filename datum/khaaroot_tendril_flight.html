khaaroot_tendril_flight
/datum/khaaroot_tendril_flight

One shot owns its beam through both projectile travel and the native return throw. The throw callback retains only a weak reference, so cancellation never leaves a deleted flight alive.

Vars

action_refCurrent mutation action, invalidated by removal, concealment, or body transfer.
beamVisual connection, replaced with an owner-to-victim beam after impact.
finishedGuard the landing boundary against repeated or reentrant completion.
owner_refThe body which launched this shot, never a replacement body on the same mind.
projectile_refThe projectile, until it hits or expires.
retractingProjectile deletion must not cancel a return throw which has already started.
victim_refThe actual hit victim, during the native return throw.

Procs

get_actionResolve through the shared item validator, which checks current body, membership, and held slot.
launchConfigure all ownership before firing: an adjacent hit can start and finish synchronously.
projectile_deletedRelease a missed projectile immediately, while allowing its successful return beam to outlive it.
retractBegin a real collision-sensitive return throw; finishing that throw is not itself proof of arrival.
