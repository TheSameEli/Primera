torn_wall
/datum/component/torn_wall

Component applied to a wall to progressively destroy it. If component is applied to something which already has it, stage increases. Wall is destroyed after three full-strength applications. Can be fixed using a welder

Vars

current_stageNative tear damage minus the first full-strength hit; fractional blows share the same repair state.

Procs
