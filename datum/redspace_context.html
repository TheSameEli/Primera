redspace_context
/datum/redspace_context

Round state for the redspace field: background, active z-levels, influence profile and zone susceptibility coefficients. The subsystem reads this datum instead of branching on specific events, round traits or admin tooling.

Vars

active_profileProfile data selected for the round. The id remains available for compact payloads.
active_profile_idIdentifier of the influence profile selected for the round.
active_z_levelsZ-levels covered by the field.
additional_z_levelsExtra z-levels explicitly enabled during this round, retained on refresh.
background_valueSlowly changing round background value.
enabledWhether the field should run at all. Any provider may veto the system.
providersAssociative list of provider id -> /datum/redspace_context_provider.
zone_coefficientsCached susceptibility coefficients by hex key. Rebuilt on refresh().

Procs

add_providerRegisters a provider. Duplicate ids are rejected so refresh stays deterministic.
get_zone_coefficientReturns the susceptibility coefficient for a hex, asking providers on the first request and caching the result. The strongest proposed restriction wins.
refreshCollects background, active z-levels, profile and enabled flag from all providers. Later background and profile proposals override earlier defaults, z-levels are unioned, and any explicit FALSE disables the system.
