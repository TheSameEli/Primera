redspace_field_source
/datum/redspace_field_source

A spatial contribution to the redspace field. Sources are sampled only for sparse cells created by observers or active zones.

Vars

change_reasonHuman-readable reason for the latest registration or change. Kept for the journal.
coverage_cell_keysCompleted cell coverage retained between refreshes. Moving waves only rebuild this coverage after crossing one cell radius.
coverage_cell_lookupLookup form of coverage_cell_keys used by pruning.
coverage_refresh_cell_keysOld and newly discovered cells waiting for a targeted refresh.
coverage_turfsResumable coverage discovery for large sources.
expires_atworld.time when the source expires. Null sources persist until removed.

Procs

can_affectCheap square-distance rejection used before the contribution calculation. Wave sources override this because their center moves independently of origin_x/origin_y.
contribution_for_distanceShared radial falloff. Quadratic falloff avoids a square root in the sampling path.
get_contributionReturns this source's contribution at a canonical map tile.
get_remaining_lifetimeRemaining lifetime in deciseconds. Null for persistent sources.
requires_processingWhether the subsystem must track this source between registration and removal.
set_positionMoves the source origin on the same z-level. Returns TRUE when the position changed.
