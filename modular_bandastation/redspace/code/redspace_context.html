modular_bandastation/redspace/code/redspace_context.dm

/datum/redspace_contextRound state for the redspace field: background, active z-levels, influence profile and zone susceptibility coefficients. The subsystem reads this datum instead of branching on specific events, round traits or admin tooling.
/datum/redspace_context_providerSupplies part of the round context. Providers must stay cheap: they are consulted on refresh() and on every uncached zone coefficient lookup. Returning null means the provider has no opinion and the next provider decides.
/datum/redspace_context_provider/defaultMVP defaults: station z-levels, calm background, the demonic profile and the single bridge susceptibility exception resolved through the hex representative point.
