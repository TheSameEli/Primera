/datum/redspace_eventBase type for explicit redspace events. Events are kept outside SSredspace so they can be registered independently later.
/datum/redspace_event/spawnAbstract event family for content that leaves a turf, object or mob behind. Concrete profile content should inherit one of the typed children below and provide event_id/start().
/datum/redspace_event/spawn/turfFuture events that replace or create terrain.
/datum/redspace_event/spawn/objectFuture events that create persistent objects or scenery.
/datum/redspace_event/spawn/mobFuture events that create redspace creatures.
/datum/redspace_event_budgetPer-hex event budget. It is created only for zones that actually attempt an event.
/datum/redspace_event/calm_echoFirst safe content event: a short local distortion with no damage or forced status effect.
/datum/redspace_event/local_distortionFirst safe content event: a short local distortion with no damage or forced status effect.
/datum/redspace_event/storm_pulseA telegraphed storm effect. Moving off the marked tile before the impact is the countermeasure.
/datum/redspace_event/lightningFirst manual event used to verify target selection, logging, and visual exposure.
